# 音乐小卡生成器

一个纯前端、单文件的音乐小卡设计工具，用浏览器打开即可使用，无需安装任何依赖。

- 画布尺寸：59 × 89 mm（含 2mm 出血）
- 成品尺寸：55 × 85 mm
- 分辨率：300 dpi

## 使用方法

直接用浏览器（推荐 Chrome / Edge）打开 `音乐小卡生成.html` 即可，所有处理均在本地完成，不上传任何数据。

## 功能

1. **封面**：上传正方形封面图（或拖拽图片到页面），支持「方形封面」和「唱片样式」两种呈现方式
2. **文字**：自定义歌曲名称、歌手 / 艺人
3. **进度条 & 播放组件**：输入当前时间 / 总时长自动生成进度比例（支持 mm:ss 和 hh:mm:ss）；下方可切换播放控件、播放器 Logo（内置图标，也支持上传自定义 Logo）或不显示
4. **背景**：
   - 封面取色：从封面主色自动生成渐变，可「换一版配色」或手动微调
   - 主题渐变：内置 14 款配色主题
   - 纯色模式
   - 支持渐变角度、背景明暗、柔光效果调节
5. **字体 / 字号**：5 种字体风格（现代黑体、优雅衬线、圆体、等宽、英文古典），字号以 mm 为单位精细调节；支持字体配置的 JSON 导入 / 导出
6. **导出**：
   - `CMYK TIFF · 300dpi 含出血`：印刷专用，已做色域压缩与限墨（单色 ≤95%、总墨量 ≤300%），可直接交印厂
   - `PNG（RGB）· 含出血`：59×89mm，屏幕预览 / 网络用图
   - `PNG（RGB）· 成品尺寸`：55×85mm，裁掉出血

## 印刷说明

- 浏览器只能渲染 sRGB，工具内置近似 CMYK 印刷色域模型（软打样），让屏幕预览接近印后效果
- 面板中会实时显示当前用色的 CMYK 数值，可直接报给印厂核对；总墨量超过 300% 会标黄提醒（铜版纸建议 ≤300%）
- PNG 标准只支持 RGB，印刷文件请使用 CMYK TIFF

## 技术说明

- 单个 HTML 文件，原生 Canvas 绘制，无任何第三方依赖
- 全部绘制基于 mm 单位（1 单位 = 1mm），导出时按 300dpi 换算像素
- CMYK TIFF 文件由内置的最小 TIFF 编码器生成（含 DPI 与色彩空间元数据）
